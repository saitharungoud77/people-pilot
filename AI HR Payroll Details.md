## 10. Free/Paid + Future

**FREE NOW:** Streamlit, SQLite, Custom PBKDF2 auth (NO Google/SSO), fpdf2, PyMuPDF, Pillow, pandas, all HR logic

**PAID NOW:** OpenAI API (usage based)

| Need | Option | Reason |
| --- | --- | --- |
| Hosting the app permanently | Render, Railway, Fly.io, AWS, Azure or Streamlit Community Cloud | A stable URL that stays up when this PC is off. Render and Railway have free tiers; production plans are paid. Streamlit Community Cloud is free for public apps and paid for private ones. |
| Managed database | PostgreSQL on Neon, Supabase or Amazon RDS | Concurrent users, automatic backups, point-in-time restore and no single-file risk. Free tiers exist; production is paid. |
| Higher AI limits and enterprise data terms | OpenAI pay-as-you-go or Azure OpenAI | Usage-based pricing already applies; a paid tier raises rate limits and Azure adds data residency and enterprise controls. The same code works - only the key and base URL change. |
| Real OCR for scanned documents | Azure Document Intelligence, Google Document AI or AWS Textract | Reads scanned bills, old Form 16 scans and photographed offer letters. Paid per page; far more accurate than sending an image to a general model. |
| Email and SMS notifications | Resend, SendGrid, Amazon SES, Twilio or MSG91 | Sends the in-app notification out by email or SMS (useful for approvals and payslip release). Paid per message; free tiers exist. |
| Single sign-on | Microsoft Entra ID, Google Workspace, Okta or Auth0 | Company SSO, MFA and automatic joiner/leaver handling. Paid per user; worth it once the team grows. |
| Commercial PDF licence | Artifex commercial licence for PyMuPDF | PyMuPDF is AGPL. If this app is distributed as closed-source software rather than used internally, a commercial licence is the clean option. Internal use does not trigger distribution. |
| Error monitoring and backups | Sentry, Better Stack, S3 or Backblaze B2 | Catches production errors and keeps off-site database backups. Free developer tiers exist; production is paid. |
| E-signature for letters | DocuSign, Adobe Sign or Zoho Sign | Sends generated letters for signature and stores the signed copy. Paid per envelope. |
| Statutory filing integrations | EPFO and income-tax filing utilities, or a payroll bureau API | Automates PF ECR and TDS returns once volume justifies it. Usually paid per filing or per month. |

**Tips:** use gpt-4o-mini/gpt-4.1-mini for bulk, gpt-4o only when needed
